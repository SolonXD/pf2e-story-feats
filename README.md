# PF2e — Сюжетные способности

Небольшой модуль для Foundry VTT, который включает встроенный раздел способностей кампании Pathfinder Second Edition и отображает его как **«Сюжетные способности»**.

В этот раздел можно перетаскивать способности, полученные за сюжетные события, награды Мастера и другие достижения кампании. Они не занимают обычные слоты повышения уровня.

## Установка

В меню запуска Foundry откройте **Add-on Modules → Install Module**, вставьте следующий адрес в поле **Manifest URL** и нажмите **Install**:

```text
https://github.com/SolonXD/pf2e-story-feats/releases/latest/download/module.json
```

Затем войдите в мир как Мастер, откройте **«Управление модулями» / Manage Modules**, включите **«PF2e — Сюжетные способности»** и сохраните изменения.

Для ручной установки скачайте `pf2e-story-feats.zip` из [последнего релиза](https://github.com/SolonXD/pf2e-story-feats/releases/latest) и распакуйте его в `Data/modules` на сервере Foundry. Должен получиться путь `Data/modules/pf2e-story-feats/module.json`. Перезапустите сервер.

## Использование

1. Откройте вкладку способностей персонажа.
2. Найдите раздел **«Сюжетные способности»**.
3. Перетащите обычный предмет типа **«Способность/Особенность» / Feat/Feature** прямо на заголовок раздела или внутрь него. Можно также перенести уже имеющуюся на персонаже способность.

Раздел не имеет фиксированных слотов по уровням. Описания, редактирование, перетаскивание и автоматизация правил обрабатываются системой PF2e. Права на редактирование персонажей остаются штатными.

Специальные категории проклятий и божественных/PFS-благословений PF2e обрабатывает отдельно. Для обычных сюжетных наград используйте обычные способности.

## Как работает модуль

При входе Мастера модуль включает мировую настройку `pf2e.campaignFeats`. Заголовок `PF2E.Actor.Character.FeatSlot.CampaignHeader` заменяется на «Сюжетные способности» для каждого клиента.

Если раздел Campaign Feats уже использовался, он получит новое название и сохранит содержимое. Модуль использует этот раздел, а не создает вторую независимую группу рядом с ним.

После отключения модуля и перезагрузки мира заголовок вернется к стандартному переводу Campaign Feats. Настройка раздела остается включенной, способности сохраняются. При необходимости раздел можно скрыть через **PF2e → Homebrew Elements → Campaign → Campaign Feats**; названия пунктов зависят от перевода.

## Совместимость и проверка

- Целевая версия Foundry VTT: **14**.
- Минимальная заявленная версия Pathfinder Second Edition: **8.6.1**.
- Проверены JSON, синтаксис JavaScript и состав установочного архива.
- Реализация сверена с API Foundry 14 и исходниками ветки `v14-dev` PF2e. Отдельный публичный тег PF2e 8.6.1 при подготовке не был доступен.
- Проверка в запущенном мире Foundry пока не проводилась; совместимость с изменяющими лист персонажа модулями не подтверждена.

Дополнительные библиотеки не требуются. Модуль не изменяет файлы системы или данные способностей.
